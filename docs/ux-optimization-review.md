# Tablefolk image and browsing review

Implemented responsive WebP images generated by Sharp during `prepare:web` (and therefore `dev`, `build`, and `typecheck`). Original artwork remains in the static export for enlargement and is embedded in the portable offline guide. Generated files and their dimension/variant manifest live in ignored build directories.

Collection covers and Resume cards use `srcset`, viewport-appropriate `sizes`, and intrinsic dimensions. Shared guide tools use the same generated previews. Guide headers use small thumbnails on phones; hidden homepage hero photos have desktop media sources and an inline transparent fallback, so phones never fetch those photos. Aspect ratios and actual transparent pixels are checked for all 488 generated variants.

Avalon setup has three steps with the checklist beside the relevant controls, expandable role/quest references, readable recognition instructions, and keyboard heading focus. The original role-capacity and quest models remain authoritative. Existing three-item checklist saves recover into the added role-confirmation check without changing the old indexes. The portable guide retains its complete setup and opening script together.

The homepage shows the latest unfinished game first and one Resume card initially. The reveal control keeps all six types of saved session accessible. Activity lives in `tablefolk-game-activity-v1`, separately from snapshots; user tool actions and opening a different play guide update it, while timer refreshes, locale changes, and reloads of the same guide do not. Older sessions fall back to their recently opened ordering. A compact introduction is shown to returning visitors; the first introduction stays stable while browsing and returning from a guide.

Collection filters use `q`, `players`, `duration`, and `favorites=1`. Player count and duration have allowlists, queries are bounded and stripped of control characters, and invalid values are removed from the URL. Native history updates happen in user handlers, and popstate only restores state, avoiding synchronization loops. Breadcrumbs recover the previous filtered collection; up to 20 recent filter combinations retain scroll positions in session storage. Locale changes retain query parameters. Favorite game selections remain in local storage.

Counts include preloads and lazy images loaded at those positions, using Resource Timing `transferSize` (including HTTP overhead). ## Verification

- `npm run build`: production build and 95 generated pages succeed; Next.js static export remains enabled. Vercel `outputDirectory` remains `.next`.
- `CHROME_CHANNEL=chrome npm run test:web`: 1,276 hosted-app checks pass, covering every locale/game/view at 320, 390 and 1,440 px, all six play tools, saved drafts, paused clocks, keyboard tabs, search, printing and blocked storage.
- Linux WebKit, Playwright 1.62.1 Noble container: full hosted-app suite and focused experience suite, including 320 px Avalon, all 5–10 player counts, both languages, both themes, references, role capacity, Lady of the Lake, opening scripts and checklist recovery.
- `CHROME_CHANNEL=chrome npm run test:experience`: focused checks of filter history, direct links, clear, reload, language, nonzero return scroll, Resume expansion, activity ordering, unchanged paused snapshots, WebP covers/guide previews, loaded original dialogs and focus return.
- `npm run test:images`: 488 image variants checked; final cold transfer measurements recorded above.
- `npm test`: 1,791 portable/offline regression checks pass.
- `npm run test:flows`: 144 offline game-flow checks pass.

Screenshots of collection cards, Resume cards, Avalon setup and image dialogs were inspected on phone and desktop. Browser error checks pass. The new focused checks and asset assertions are included in Linux CI for Chromium and WebKit.

## Limits

Favorites, activity and game snapshots remain device-local. Breadcrumb context and scroll positions remain tab-local. Image measurements and verification use the local static export; no deployment or Vercel dashboard change was performed.
